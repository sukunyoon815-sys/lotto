# 🎱 행운의 로또 추첨 (Lotto Draw)

1~45 중 6개 번호 + 보너스 번호를 추첨하는 로또 번호 생성기입니다.

## ✨ 주요 기능

- 🎲 로또 번호 추첨
- 📦 다중 생성 (최대 5세트)
- 🎨 한국 로또 공식 색상
- 📜 기록 저장 (최근 50개)

## 🌐 Cloudflare Pages 배포

1. GitHub에 업로드
2. Cloudflare Dashboard → Workers & Pages → Create → Pages
3. 저장소 연결 후 배포

## 🍀 주의사항

> 이 사이트는 재미를 위한 것이며, 당첨을 보장하지 않습니다.
